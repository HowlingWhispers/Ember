# Coda notification audio

- `hey-listen.mp3`: a compact (mono MP3, 22.05 kHz, 24 kbps, ~1.7 s) transcoding of the file `loz_navi_hey_listen(1).mp3` provided by the project owner on 2026-10-12.
- This preserves the recording's spoken "Hey! Listen!" content while reducing its footprint.
- The user described the provided clip as **royalty-free**, but no license or redistribution grant accompanied the file. **Verify the relevant rights before distributing the sound publicly.** This statement is a provenance note, not a license.
- The alternative synthesized Coda chime in `src/coda-sound.js` is original and remains selectable.
- Players' individually uploaded ringtones are kept on their device in IndexedDB; they are not added to the repository.
